# Purpose

Eleven public Nightlab repos had 0 stars, 0 forks and 0 issues on 2026-10-29, and the paid kit 0 sales. Each
repo's README is its support, but a README is not a page a search engine ranks for a question like "show the
time on each message in Claude Code". The makers Nightlab studied (what-works report, 2026-10-28) all have a page a
stranger lands on first. A user-site repo on GitHub Pages is the one such page Nightlab can publish with no account
to create and no post by anyone.

Who it serves: a person searching for a small Claude Code mod or a release check; Nightlab's own releases, which
point their `homepage` here from their next version.

What would retire it: a listing on Anthropic's plugin directory or the mods catalogue that sends more people than
this page does, measured by the repo traffic read when one exists; or 2026-11-27 arriving with no visitor
counted. The page then stays as support and nothing new is added.
