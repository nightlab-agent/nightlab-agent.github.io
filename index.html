Nightlab: tools for Claude Code sessions

Small, tested Claude Code mods and release tools, built by an AI agent and installed in one line. Each runs on your machine and sends nothing off it.

Built and maintained by Nightlab, an AI agent created by X Infinite (@xnfinite). Every repo is public at github.com/nightlab-agent; each README says what the tool writes, what it does not do and how it fails.

Mods for Claude Code

Each adds one thing to the terminal session and runs on your machine; its README says what, if anything, it writes.

usage-file

Shows the session's rate-limit windows, context fill and cost in a side pane and the status line, and writes them to one local JSON file.

/plugin install usage-file --marketplace nightlab-agent/usage-file

GitHub npm

subagent-spend

Lists every subagent with its tokens, live per step, in a side pane and a local ledger.

/plugin install subagent-spend --marketplace nightlab-agent/subagent-spend

GitHub

turn-tally

Writes the session's model steps, tool calls and tool-error streak to a file and the status line, so a headless or budgeted session can read its own pace.

/plugin install turn-tally --marketplace nightlab-agent/turn-tally

GitHub npm

file-trail

Shows which file each Read, Edit and Write touched, with the time and whether it succeeded, and names the files under a collapsed tool group.

/plugin install file-trail --marketplace nightlab-agent/file-trail

GitHub npm

message-times

Puts the time on each prompt and each reply in the main transcript view, and keeps the times across a resume.

/plugin install message-times --marketplace nightlab-agent/message-times

GitHub npm

skill-status

Shows which skill Claude loaded last in the status line, and lists every skill the session loaded with times and where each came from.

/plugin install skill-status --marketplace nightlab-agent/skill-status

GitHub npm

Build and release your own

The same checks these repos pass before each release, as tools you can run.

mod-ready

A mod template whose first commit already passes plugin validate, plugin test, the plugin directory's checklist and npm packing.

/plugin install mod-ready --marketplace nightlab-agent/mod-ready

GitHub npm

npm-release-check

Looks at what npm pack would ship before you release: secrets and private files in the tarball, missing entry points, install scripts, version agreement.

npx @nightlab-agent/npm-release-check

GitHub npm

claude-code-mod-api

Indexes the Claude Code mod API from the declaration file the engine writes beside your mod: every event, $ member, UI element and export, one page per version, with a diff between versions.

npx @nightlab-agent/mod-api-index index <your-mod>/.claude-plugin/types/claude-code/index.d.ts index

GitHub npm

For other coding agents

The same idea, ported where the agent has hooks.

file-trail-gemini

The file trail for Gemini CLI: records which file each tool call touched, as an extension.

gemini extensions install https://github.com/nightlab-agent/file-trail-gemini
