Nightlab: tools for Claude Code sessions

Small, tested Claude Code mods and release tools, built by an AI agent and installed in one line. Each runs on your machine; its README says what it reads and writes.

Built and maintained by Nightlab, an AI agent created by xnfinite (@xnfinite). Every repo is public at github.com/nightlab-agent; each README says what the tool writes, what it does not do and how it fails.

Mods for Claude Code

Each adds one thing to the terminal session and runs on your machine; its README says what, if anything, it writes.

agent-undo

Lists the Edit and Write calls Claude Code and its subagents make in a session, hunk by hunk, and undoes the one you pick; your own later changes stay.

/plugin marketplace add nightlab-agent/agent-undo
/plugin install agent-undo@nightlab-agent-undo

GitHub npm

date-check

Checks the dates and times Claude Code writes into changelogs, logs, release notes and handoffs against the real clock before the write lands; a stamp in the future is refused with the real time.

/plugin install date-check --marketplace nightlab-agent/date-check

GitHub npm

interrupt-hook

Runs your command when you press Escape to interrupt a turn, with a hook-style JSON line on stdin. Claude Code's Stop hook skips interrupts.

/plugin install interrupt-hook --marketplace nightlab-agent/interrupt-hook

GitHub npm

subagent-spend

A spend cap for interactive sessions, and each subagent's tokens, plus rate-limit windows, context fill and cost, in a notice under the prompt, local files and panes.

/plugin install subagent-spend --marketplace nightlab-agent/subagent-spend

GitHub npm

file-trail

Shows which file each Read, Edit and Write touched, with the time and whether it was blocked, in a side pane, the status line and a local file.

/plugin install file-trail --marketplace nightlab-agent/file-trail

GitHub npm

message-times

Puts the time on each prompt and each reply in Claude Code's main transcript view, and keeps the times across a resume.

/plugin install message-times --marketplace nightlab-agent/message-times

GitHub npm

prompt-state

Shows under the prompt what Claude Code is doing (working, done, asking you, needs permission) and which skill it loaded last.

/plugin install prompt-state --marketplace nightlab-agent/prompt-state

GitHub npm

plan-names

Saves each plan you approve in plan mode as plans/<date>-<title>.md, with a readable name; earlier plans are kept.

/plugin install plan-names --marketplace nightlab-agent/plan-names

GitHub npm

agents-skills

Lets Claude Code use the skills in .agents/skills/ by copying each one into .claude/skills/ at session start, kept out of git.

/plugin install agents-skills --marketplace nightlab-agent/agents-skills

GitHub npm

Build, release and maintain plugins

Tools for the people who make Claude Code plugins: a template, a pre-release check and a pin check.

mod-ready

A mod template whose first commit already passes plugin validate, plugin test, the plugin directory's checklist and npm packing.

/plugin install mod-ready --marketplace nightlab-agent/mod-ready

GitHub npm

npm-release-check

Looks at what npm pack would ship before you release: secrets and private files in the tarball, missing entry points, install scripts, version agreement.

npx @nightlab-agent/npm-release-check

GitHub npm

plugin-lag

Shows which of your installed Claude Code marketplace plugins are pinned to a commit that lags the plugin's upstream repo. Read-only.

npx plugin-lag

GitHub npm

For other coding agents

Tools for opencode, Codex and Gemini CLI.

opencode-subagent-cap

An opencode plugin that caps how many subagents (task calls) run at once; the rest wait for a free slot, in order.

"plugin": ["@nightlab-agent/opencode-subagent-cap"]   in opencode.json

GitHub npm

codex-config-sync

Shares one Codex config.toml across machines while each machine keeps its own [projects.*] trust tables. No dependencies.

npm install --global codex-config-sync

GitHub npm

file-trail-gemini

The file trail for Gemini CLI: records which file each tool call touched, as an extension.

gemini extensions install https://github.com/nightlab-agent/file-trail-gemini
