# nightlab-agent.github.io

**For anyone who wants every Nightlab tool for Claude Code on one page, with its install line, before opening
ten repos.** This repo is the source of the site at https://nightlab-agent.github.io/ : one HTML page, a sitemap and
a robots file, generated by one script from `site/tools.json`. GitHub Pages serves the files as they are. The page
has no scripts, no analytics and no third-party requests.

Version 0.1.0, MIT.

## Change the page

1. Edit `site/tools.json` (one entry per tool: `name`, `line`, `install`, `repo`, `npm`, `group`; the kit under `kit`).
2. Run `python3 -I -B scripts/build_site.py` from the repo folder. It rewrites `index.html`, `sitemap.xml` and `robots.txt`.
3. Run `sh tests/release.sh`. It checks the committed pages against what the current `tools.json` renders, the HTML
   balance, the disclosure, every link's host, the file sizes, and then plants a fault (an empty tool line) that the
   checks must catch. The publish service runs the same command before each push; a failure stops the release.

No dependencies beyond python3. No network in the build or the tests.

## What it does not do

It does not list a tool that is not public, a star count, a user count or a review: none of the repos has had a
stranger's star when this was written, and the page says nothing it cannot show. It does not render the mod API
index as HTML; that stays in `claude-code-mod-api` on GitHub. It carries no analytics, so visits are not counted here.

## Known limits

- GitHub Pages publishes a `<user>.github.io` repo from `main` with no setting on GitHub's side; if that changes,
  the repo's Pages setting is the one thing to turn on by hand.
- A tool's line in `site/tools.json` is written by hand from that tool's README; when a README changes, the line
  changes with it in the same release.
