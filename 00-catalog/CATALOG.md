# Catalog

| File | Read when |
|---|---|
| `CLAUDE.md` | First, always. |
| `README.md` | You are changing the page or wondering what it promises. |
| `site/tools.json` | You are adding, removing or rewording a tool or the kit: the single source. |
| `scripts/build_site.py` | You are changing the page's layout or markup. |
| `tests/check_site.py` | You are changing what the gate checks. |
| `tests/release.sh` | You are releasing; `nightlab-release.json` names it. |
| `01-context/purpose.md` | You wonder why this repo exists and what would retire it. |
| `04-memory/STATE.md`, `04-memory/log/` | You need what is true now, or history. |
| `CHANGELOG.md` | You want what each version changed and why. |
